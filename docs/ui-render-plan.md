# FitAgent UI 重排方案（图标短标签 / 图表 / 留白）

日期：2026-10-14。对应提示词 `Codex_UI重渲染_图标短标签_图表与留白.md` §9：**先写这份对照表，再动代码**。
本文只回答"原有功能去哪了、用什么图形替代文字"，配色与 token 见 `docs/ui-style-guide.md`（不另起一套规范）。

## 1. 导航：3 个 tab → 4 个 tab（路由全部保持兼容）

| tab | 路由 | 变化 | 说明 |
|---|---|---|---|
| 首页 | `pages/index/home` | 路径不变 | 重排为四层（§4 提示词） |
| 训练 | `pages/plan/list` | 文案「训练计划」→「训练」，加图标 | 仍是计划列表，不新建页面 |
| 教练 | `pages/coach/chat` | **从 navigateTo 提升为 tab**，加图标 | 该页不读任何入参（`onLoad` 无参数），提升后 `switchTab` 不丢上下文；历史会话仍是它的二级页 |
| 我的 | `pages/mine/index` | 路径不变 | 改为头像区 + 图标短标签分组入口 |

其余 10 个页面路径**一个都不改**，`navigateTo`/`switchTab` 调用点只调整目标语义（例如首页原「去看计划」用 `switchTab`，仍用 `switchTab`）。

## 3. 新增/改造的组件（不造平行组件库，命名沿用 `Fa*`）

| 组件 | 职责 | 替代掉什么 |
|---|---|---|
| `FaIcon.vue` | 统一线性图标：`name` + `tone`，SVG 经 base64 打进 WXSS | 页面里的文字箭头、Emoji |
| `FaIconTile.vue` | 图标 + 两字标签 + **一个**落点 | 首页/我的页的长标题入口卡 |
| `FaMetricCard.vue` | 关键数字 + 单位 + 短标题 + 可选小图 | 「当前体重是…kg」这类整句 |
| `FaTrendChart.vue` | `canvas type="2d"` 真实体重折线（dpr、尺寸查询、重绘、卸载清理） | 无（新增能力） |
| `FaSegmented.vue` | 7天/30天、分类切换 | 一排 chip 说明 |
| `FaDayStrip.vue` | 计划七日条选 | 整周展开 |
| `FaMoreMenu.vue` | 收纳次级操作（复制/归档/删除/字典） | 成排按钮 |
| `EmptyState.vue`（改造） | 图形 + 短标题 + 一句 + 一个操作 | 长段解释 |
| 全局 `.fa-tiles` / `.fa-metrics` / `.fa-toolbar` / `.fa-bottom-bar` | 2 列网格、指标行、工具条、底部安全区 | 各页复制的布局代码 |

## 4. 明确**不做**的图形（无数据源就是假图，宁缺）

- 组数/时长完成度进度环、训练日历点阵、本周训练场次柱状图：**阶段 2 未实施**，
  `workout_session/entry/set` 与 metrics 表在 V1–V22 里不存在，也没有统计接口（`docs/feature-audit-before.md` §4）。
  提示词 §7「没有对应统计接口时，使用已有真实记录能支持的展示」→ 本轮只落地**体重折线**这一个真数据图表。
- 首页不放"完成度 0%/100%"占位；训练入口（哑铃）不进首页四宫格，因为点进去没有真实能力。

## 5. 文字删减边界（提示词 §2.3）

**删/移**：首页三段口径长句、区块副标题、开发术语（接口路径、错误码释义）、重复的"查看/前往"按钮文案。
**保留必要长度**：表单字段标签与填写提示、删除/撤销/登录失效/预算停止/费用未知确认文案、错误码 + traceId、
用户问题与 AI 正文、动作名称/组数/次数/单位/币种、数据不足与图表口径（改短提示 + 点按详情）。

## 6. 尺度基线与已知偏差

留白/圆角/图标/关键数字按提示词 §6 的 rpx 基线落地（新增 token 见 `uni.scss`）。
**字号保留项目既有高密度尺度**：UI 文本 15px、成段阅读 19px、可点区域 44px——这是用户跨轮次确认过的偏好，
提示词的 28–30rpx（≈14–15px）与之相容，故短标签取 30rpx、正文不降到 13px 以下；偏差记录在 `docs/ui-style-guide.md` §3。
